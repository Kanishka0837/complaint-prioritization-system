# Digital Complaint Prioritization System

This project prioritizes municipal complaints using Data Structures & Algorithms.

## Tech Used
- C++
- HTML
- JSON

## Algorithms Used
- Max Heap (Priority Queue)
- Graph (Adjacency List)
- Dijkstra’s Algorithm
- Hash Map
- Greedy Algorithm
- Merge Sort

## Note
This project was developed with the assistance of AI tools, and I focused on understanding and structuring the logic.
