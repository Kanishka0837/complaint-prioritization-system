# Digital Complaint Prioritization System

This project prioritizes municipal complaints using Data Structures & Algorithms.

## Tech Used
- C++
- HTML
- JSON

## Algorithms Used
- Max Heap (Priority Queue)
- Graph (Adjacency List)
- Dijkstra’s Algorithm
- Hash Map
- Greedy Algorithm
- Merge Sort


## Development Note
This project was built using modern development tools and focuses on applying data structures and algorithms to solve real-world problems.
